## What it is

A single-tenant PR reviewer you run on your machine. No login. Bind loopback.

Reviewers run as `opencode run` in Docker and write files under `.gegenlesen/`. The host unpacks with libarchive, runs deterministic checks first, then the two model slots, then the judge.

## What Ledger is

The React admin UI. Jobs, findings, thumbs, rules, context, learnings. That is the shop book, not the front door.
